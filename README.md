# 🌸 Sarangê — Meu amor por doramas

**Sarangê** é um sistema web desenvolvido como projeto acadêmico, com o objetivo de apresentar uma estrutura inicial de autenticação e navegação entre telas.

O projeto foi inspirado no universo dos doramas e utiliza uma identidade visual delicada, com cores suaves e elementos relacionados à cultura coreana.

## 🎯 Objetivo do projeto

Desenvolver um sistema web com telas de Login, Cadastro e Painel Operacional, explorando componentes, organização do código e navegação entre interfaces.

## ✨ Funcionalidades

- **Login:** acesso ao sistema por meio de e-mail e senha.
- **Cadastro:** criação de usuário com validação dos campos e confirmação de senha.
- **Painel Operacional:** acesso a uma área inicial preparada para receber futuras funcionalidades.
- **Navegação:** transição entre as telas de login, cadastro e painel.
- **Logout:** encerramento da sessão e retorno à tela de login.

## 🛠️ Tecnologias utilizadas

## 🚀 Como executar o projeto

É necessário ter o Node.js instalado.

**1. Clone o repositório:**

```bash
git clone https://github.com/RamayannaG/sarange.git
```

**2. Entre na pasta do projeto:**

```bash
cd sarange
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Execute o projeto:**

```bash
npm run dev
```

**5. Acesse no navegador:**

```text
http://localhost:5173
```

## 📌 Considerações finais

O Sarangê representa a etapa inicial de desenvolvimento de um sistema web, com foco na construção de interfaces, reutilização de componentes e navegação entre telas.

O painel operacional foi mantido inicialmente vazio, conforme a proposta acadêmica, permitindo a expansão do sistema em futuras etapas.
